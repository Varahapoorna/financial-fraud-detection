# Financial Fraud Detection System

## Project Description

Financial Fraud Detection System is a machine learning-based web application that detects potentially fraudulent financial transactions.

The system analyzes transaction details and uses machine learning models to classify transactions as legitimate or potentially fraudulent.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Flask
- HTML
- CSS

## Key Features

- Fraud transaction detection
- Data preprocessing and feature encoding
- Machine learning-based prediction
- Web-based interface using Flask
- Risk classification for transactions

## How to Run

1. Install the required Python libraries:

```bash
pip install -r requirements.txt
```

2. Run the Flask application:

```bash
python app.py
```
